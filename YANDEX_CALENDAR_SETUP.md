# Настройка интеграции с Яндекс Календарем

## Описание

Интеграция с Яндекс Календарем Светланы позволяет:
1. Проверять занятые времена в календаре перед записью
2. Автоматически добавлять новые записи в календарь Светланы
3. Синхронизировать записи между сайтом и календарем

## Шаги настройки

### 1. Создание приложения в Яндекс

1. Перейдите на https://oauth.yandex.ru/
2. Нажмите "Зарегистрировать новое приложение"
3. Заполните форму:
   - **Название**: SvetSalonPro Calendar
   - **Платформы**: Web-сервисы
   - **Callback URI**: `https://ваш-домен.ru/api/yandex-calendar/callback`
   - **Права доступа**: 
     - `calendar:read` - чтение календаря
     - `calendar:write` - запись в календарь
4. Сохраните **Client ID** и **Client Secret**

### 2. Получение OAuth токена

#### Вариант 1: Через OAuth авторизацию (рекомендуется)

1. Откройте в браузере:
```
https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
```

2. Авторизуйтесь аккаунтом Светланы
3. Скопируйте токен из URL после редиректа

#### Вариант 2: Через API (для серверных приложений)

Используйте Client ID и Client Secret для получения токена через API.

### 3. Получение ID календаря

1. Используйте API Яндекс Календаря для получения списка календарей:
```bash
curl -H "Authorization: OAuth ВАШ_ТОКЕН" \
  "https://calendar.yandex.ru/api/v1/calendars"
```

2. Найдите нужный календарь и скопируйте его ID

### 4. Настройка переменных окружения

Добавьте в файл `.env` или в переменные окружения сервера:

```env
YANDEX_CALENDAR_TOKEN=ваш_oauth_токен
YANDEX_CALENDAR_ID=id_календаря_светланы
```

### 5. Проверка работы

1. Сделайте тестовую запись на сайте
2. Проверьте, что событие появилось в Яндекс Календаре Светланы
3. Проверьте, что занятое время в календаре блокируется на сайте

## API Endpoints

### Проверка занятых времен
```
GET /api/yandex-calendar/busy-times?date=2025-01-15
```

### Проверка доступности времени
```
GET /api/yandex-calendar/check-time?date=2025-01-15&time=14:00&duration=60
```

### Создание события
```
POST /api/yandex-calendar/create-event
Content-Type: application/json

{
  "title": "Запись: Стрижка",
  "description": "Клиент: Иван\nТелефон: +7...",
  "date": "2025-01-15",
  "time": "14:00",
  "duration": 60
}
```

## Важные замечания

1. **Токен имеет срок действия** - может потребоваться обновление через определенное время
2. **ID календаря** - если Светлана создаст новый календарь, нужно будет обновить ID
3. **Ошибки** - если Яндекс Календарь недоступен, система продолжит работать, но без синхронизации
4. **Безопасность** - храните токены в переменных окружения, не коммитьте их в репозиторий

## Устранение проблем

### События не создаются
- Проверьте правильность токена
- Убедитесь, что у токена есть права `calendar:write`
- Проверьте ID календаря

### Времена не блокируются
- Проверьте, что токен имеет права `calendar:read`
- Убедитесь, что события в календаре имеют правильный формат времени
- Проверьте логи сервера на наличие ошибок

### Ошибка авторизации
- Токен мог истечь - получите новый
- Проверьте правильность формата токена (должен начинаться с "OAuth ")
